# Capitão Verde Run 🌿

> **"Restaurar o equilíbrio, uma corrida de cada vez."**

**Capitão Verde Run** é um *infinite runner* em 3D desenvolvido com React, Three.js e tecnologias modernas web. O jogador assume o papel do **Capitão Verde**, um herói ecológico em uma missão para limpar uma cidade futurista poluída, coletar letras para restaurar a palavra **V-E-R-D-E** e subir no Ranking Global de sustentabilidade.

![Menu Screen](/public/menu_wide.jpg)

## 🎮 Como Jogar

1.  **Objetivo**: Corra o mais longe possível desviando de obstáculos (lixo, barreiras).
2.  **Missão**: Colete as letras flutuantes **V - E - R - D - E**. Ao completar a palavra, você avança de nível e a velocidade aumenta.
3.  **Pontuação**: 
    -   Coletar letras e Gems Azuis aumenta sua pontuação.
    -   Sobreviver por mais tempo garante mais pontos.
4.  **Ranking**: Ao final da missão (Tela de Vitória), registre seu nome no **Ranking Global** e veja como você se compara a outros Capitães.

## 🚀 Tecnologias

Este projeto utiliza uma stack moderna e performática:

-   **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
-   **3D Graphics**: [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) (Three.js)
-   **State Management**: [Zustand](https://github.com/pmndrs/zustand)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Backend / Database**: [Supabase](https://supabase.com/) (para o Leaderboard)
-   **Deploy**: [Vercel](https://vercel.com/)

## 🛠️ Instalação e Execução

Siga os passos abaixo para rodar o projeto localmente:

### 1. Clone o Repositório
\`\`\`bash
git clone https://github.com/sreliakim25/cap_verde.2.git
cd cap_verde.2
\`\`\`

### 2. Instale as Dependências
\`\`\`bash
npm install
\`\`\`

### 3. Configuração do Supabase (Obrigatório para Ranking)
Para que o Ranking Global funcione, você precisa de um projeto no Supabase:

1.  Crie um projeto gratuito em [supabase.com](https://supabase.com).
2.  No **SQL Editor**, rode o seguinte comando para criar a tabela:
    \`\`\`sql
    create table leaderboard (
      id bigint generated by default as identity primary key,
      name text not null,
      score bigint not null,
      created_at timestamp with time zone default timezone('utc'::text, now()) not null
    );
    \`\`\`
3.  Crie um arquivo \`.env\` na raiz do projeto e adicione suas chaves (pegue em Project Settings > API):
    \`\`\`env
    VITE_SUPABASE_URL=sua_url_do_supabase
    VITE_SUPABASE_ANON_KEY=sua_chave_anonima
    \`\`\`

### 4. Rode o Projeto
\`\`\`bash
npm run dev
\`\`\`
O jogo estará rodando em \`http://localhost:5173\`.
